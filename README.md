# SKSE Plugins Updater

A read-only SKSE compatibility scanner for Mod Organizer 2. Work in progress.

The first milestone identifies active SKSE DLLs and reports runtime compatibility evidence. Reviewed Nexus updates and sequential MO2 installation are planned; this version does not download, install, or modify mods.

Source code lives in `src/`. Reference repositories, local scan reports, credentials and development notes are not part of this repository.
